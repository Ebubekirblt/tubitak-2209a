# girenit Türkçe sentetik veri seti

Bu veri seti tamamen sentetik Türkçe konuşmalardan oluşur. `train/` eğitim,
`test/` bağımsız değerlendirme için kullanılır. Manifestte sesler
`label=0` olarak işaretlenir.

Sesler mono WAV biçimindedir. Kaynak ve üretim bilgileri `provenance/`
klasöründeki manifestlerde tutulur. Veri seti Apache License 2.0 kapsamındadır;
ayrıntılar için mevcut `README.md` dosyasına bakın.
