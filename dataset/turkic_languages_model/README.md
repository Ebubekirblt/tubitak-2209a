# TurkicASR yardımcı modeli

Bu klasör Türkçe konuşmayı metne dönüştürme süreçlerinde yardımcı olarak
kullanılan TurkicASR model çıktısını içerir. Anti-spoofing sınıflandırıcısının
ana modeli değildir.

Büyük model ve deney dosyaları Git’e eklenmez. Modeli kullanacak araç,
gereken ağırlık ve yapılandırma dosyalarını bu klasör altında aramalıdır.
