# Synthetic Turkish TTS Data

Bu klasör, farklı alanlarda üretilmiş sentetik Türkçe konuşma verilerini
içerir. Veri setindeki sesler manifestte `label=0` olarak işaretlenir.

Veri dosyaları `data/` altında parquet biçimindedir. WAV dosyalarına
dönüştürme veya Hugging Face `datasets` ile okuma yapılmadan bu klasör
doğrudan ses manifestine eklenmez.

Veri seti CC BY 4.0 lisanslıdır; kullanımda gerekli atıf verilmelidir.
Detaylar için mevcut İngilizce `README.md` dosyasına bakın.
